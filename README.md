# a1_gerativeAI

This repository is created for Assignment 1 of the Generative AI course, exploring how generative AI can be applied in the healthcare industry. It contains draft and final documents written with AI assistance, along with reflections on the prompting process.

## Git Steps Used

1. Cloned the remote repository from GitHub to local machine using `git clone`
2. Created new files (`README.md`, `assistant_draft.md`, `final_version.md`) in the local repository
3. Staged files using `git add`
4. Committed changes to the local repository using `git commit`
5. Pushed local commits to the remote GitHub repository using `git push`
